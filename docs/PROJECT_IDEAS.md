# Темы проекта: животные и мясная продукция

Сведения о датасетах проверены 12 сентября 2026 года. До скачивания необходимо
зафиксировать точную версию каждого датасета и повторно проверить лицензию.

## Что значит «две модели»

Две модели должны решать разные части одной задачи. Лучший вариант для хакатона —
каскад: первая модель находит объекты, вторая анализирует каждый найденный объект.
Так архитектура видна в демо и её пользу легко объяснить жюри.

| Место | Проект | Модель 1 | Модель 2 | Связность | Сложность |
|---:|---|---|---|:---:|:---:|
| 1 | MeatFlow AI | вид и локализация мяса | свежесть каждого фрагмента | 5/5 | 3/5 |
| 2 | PoultryGuard 360 | болезни птицы | свежесть мяса птицы | 4/5 | 4/5 |
| 3 | CattleCare AI | поведение коров | признаки заболеваний | 5/5 | 4/5 |
| 4 | Farm-to-Fork Beef | здоровье КРС | свежесть мясной продукции | 3/5 | 3/5 |

Оценки — наша инженерная оценка пригодности для хакатона, а не заявленные
характеристики датасетов.

## 1. MeatFlow AI — рекомендуемый вариант

### Идея

Система контроля мясной продукции для магазина, склада или приёмки. Пользователь
загружает фотографию лотка, витрины или партии. Приложение находит каждый кусок,
определяет тип мяса и отдельно оценивает его свежесть.

### Две модели

1. **Object detector** локализует фрагменты и определяет `beef`, `chicken` или
   `pork`.
2. **Image classifier** получает crop каждого detection и определяет
   `Fresh`/`Spoiled` или `Fresh`/`Half-Fresh`/`Spoiled` после аудита данных.

Это настоящий последовательный pipeline:

```text
изображение партии
        ↓
Model A: meat detector
        ↓ crops + тип мяса
Model B: freshness classifier для каждого crop
        ↓
состав партии + карта риска + решение по приёмке
```

### Датасеты

- Model A: [Meat Type Detection, Roboflow
  Universe](https://universe.roboflow.com/mangoo/meat-type-detection-urfyl) — 7 200
  изображений, object detection, три класса, CC BY 4.0. Версия v1 не содержит
  аугментаций и уже имеет train/validation/test split.
- Model B: [Meat Quality Detection, Roboflow
  Universe](https://universe.roboflow.com/icake/meat-quality-detection) — около
  1 900 изображений, classification, `Fresh`/`Spoiled`, CC BY 4.0.

Альтернатива для второй модели: [Meat Quality, версия
v5](https://universe.roboflow.com/techtonics/meat-quality/dataset/5) — 3 724
изображения, но у версии нет test split, а class remapping сложнее. Её стоит брать
только после проверки исходных классов и происхождения изображений.

### Что показывает приложение

- исходное и аннотированное изображение;
- карточку каждого обнаруженного фрагмента: тип, свежесть, уверенность обеих
  моделей;
- долю подозрительной продукции и решение `принять`, `проверить вручную` или
  `отклонить партию` по настраиваемому правилу;
- журнал партий, сравнение поставщиков и экспорт CSV/PDF;
- версии обеих моделей и latency всего каскада.

### Риски

Свежесть нельзя надёжно подтвердить только по RGB-фото: запах, температура,
микробиология и условия хранения остаются вне модели. Поэтому интерфейс должен
называть результат **визуальным скринингом**, а не санитарным заключением.

Главная техническая проверка — перенос classifier на crops, созданные detector.
Нужно вручную разметить небольшой совместный holdout из реальных фотографий и
оценить весь каскад, иначе хорошие отдельные метрики ничего не докажут.

## 2. PoultryGuard 360 — самая сильная отраслевая история

### Идея

Два пункта контроля птицеводческого предприятия в одном интерфейсе. На ферме
сотрудник проверяет птицу на визуальные признаки проблем. На приёмке продукции
второй модуль выполняет визуальный скрининг свежести мяса птицы. Результаты
привязываются к одной партии и формируют журнал контроля.

### Две модели и данные

1. **Chicken disease detector:** [Chicken Disease Detection v4, Roboflow
   Universe](https://universe.roboflow.com/nyxus/chicken-disease-detection-djh8g/dataset/4) —
   3 028 изображений в выбранной версии, object detection, CC BY 4.0, без
   аугментаций в опубликованной версии.
2. **Poultry freshness classifier:** [RGB Poultry Meat Freshness, Roboflow
   Universe](https://universe.roboflow.com/cv6161-term-paper/rgb-poultry-meat-freshness-0dkib) —
   1 730 изображений, `Fresh`/`Rotten`, classification, CC BY 4.0.

### Почему это интересно

Проект охватывает животное и мясную продукцию, использует две разные ML-задачи и
даёт сильную презентационную историю «от фермы до приёмки». Можно показать две
роли: ветеринарного помощника и контролёра качества.

### Риски

Модели не работают последовательно на одном изображении. Их объединяет партия и
workflow, поэтому потребуется честно реализовать карточку партии, два пункта
контроля и итоговый статус. Модуль заболеваний является инструментом
предварительного отбора для осмотра ветеринаром, а не диагнозом.

## 3. CattleCare AI — две модели только по животным

### Идея

Видеоаналитика для фермы: одна модель отслеживает поведение животных, вторая
анализирует выбранные кадры на визуальные признаки заболеваний. Приложение ищет
изменения активности и формирует очередь животных для осмотра.

### Две модели и данные

1. **Behavior detector:** [Cattle Dataset Behavior, Roboflow
   Universe](https://universe.roboflow.com/cattle-diseasee-computer-vision-dataset/cattle-dataset-behavior-cqtzu) —
   3 811 изображений, object detection, девять классов поведения, CC BY 4.0.
2. **Disease classifier:** [New Cattle Diseasee, Roboflow
   Universe](https://universe.roboflow.com/cattle-diseasee-computer-vision-dataset/new-cattle-diseasee-hzipc) —
   3 647 изображений, classification, восемь заявленных классов, CC BY 4.0.

### Сильная сторона

Обе модели обслуживают одного пользователя и одну ферму. Model A может выбирать
подозрительные кадры по падению/долгому лежанию, после чего Model B выполняет
визуальный скрининг. Получается продукт для раннего внимания, а не каталог
классификаторов.

### Риски

Датасеты собраны независимо и не содержат общего идентификатора животного. В
публичном наборе поведения есть пересекающиеся и неоднозначные классы вроде
`standing` и `stand-Eat-Sit-Fall`; class map обязательно нужно очистить до
обучения. Медицинские выводы должен подтверждать ветеринар.

## 4. Farm-to-Fork Beef

### Идея

Единый журнал двух пунктов контроля: визуальный скрининг здоровья КРС перед
отправкой и контроль внешнего вида мясной продукции при приёмке. Две модели
независимы, но работают с одной партией и формируют итоговый audit trail.

### Две модели и данные

1. Cattle disease classifier из CattleCare AI: 3 647 изображений, восемь классов,
   CC BY 4.0.
2. Meat Quality Detection classifier из MeatFlow AI: около 1 900 изображений,
   `Fresh`/`Spoiled`, CC BY 4.0.

### Когда выбирать

Этот вариант подходит, если организаторы особенно ценят прослеживаемость цепочки
поставок. Для технической защиты он слабее MeatFlow AI: две модели не образуют
каскад и обучены на несвязанных данных. Нельзя утверждать причинную связь между
здоровьем конкретного животного и оценкой конкретного куска мяса.

## Рекомендуемый MVP для MeatFlow AI

1. Обучить detector мяса и freshness classifier отдельными командами.
2. Собрать собственный совместный test set минимум из 100 сцен, где на одном
   изображении может быть несколько фрагментов.
3. Реализовать каскад `detect → crop → classify → aggregate` с независимыми
   версиями и confidence thresholds.
4. Поднять FastAPI и Streamlit поверх одного application use case.
5. Добавить загрузку фото и короткого видео, ручное исправление результата и
   журнал партий в SQLite.
6. Показать метрики каждой модели и end-to-end метрику: долю объектов, для которых
   одновременно правильно определены тип и визуальное состояние.
7. Сохранить offline demo с подготовленными примерами на случай отсутствия сети.
